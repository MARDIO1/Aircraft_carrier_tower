# 飞书 MCP 接入预研

当前仓库先不假设已接入 Feishu MCP。第一阶段目标是把数据结构和同步策略定下来，等 connector 可用后直接接上。

## 先确认的能力

- 云文档创建与更新
- 表格/多维表格写入
- 文件和图片上传
- 文档权限范围
- 同一文档被人工编辑时的冲突处理

## 建议的第一版同步

1. 每个黑匣子 CSV 对应一个分析页。
2. 把摘要、相关性、FFT 峰值和结论写到云文档。
3. MATLAB 生成的图表先导出为本地文件，后续再批量上传。
4. 人工编辑和自动写入先分层，避免抢同一段内容。

## 本地骨架

- `src/feishu_sync.py` 负责把报告转成 Markdown 草稿。
- `analysis_reports/feishu_drafts/` 目录保存待同步内容。
- 后续接 Feishu MCP 时，只需要把草稿写入接口层，而不必重做分析逻辑。
